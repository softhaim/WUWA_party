# Resonance Lab

명조: 워더링 웨이브의 보유 캐릭터, 육성 상태, 사용 가능 횟수와 무기 상태를 기록하고 여러 파티를 계정 단위로 배분하는 Python 웹 앱입니다.

## 실행

외부 패키지가 필요하지 않습니다.

```bash
python3 server.py
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다.

## 테스트

```bash
python3 -m unittest discover -s tests -v
```

## 현재 기능

- 2026-08-21 기준 캐릭터 58명
  - 3.6 신규 캐릭터 청초, 경연 포함
  - Nanoka 기반 고해상도 카드 이미지, 상세 일러스트, Live2D 데이터 연결
- 이름·속성·무기·레어도·역할 검색 및 아이콘 필터
- 보유 여부, 공명 체인, 레벨, 육성 상태, 최대 사용 횟수, 전용 무기와 재련 저장
- 레벨 `MAX 90` 단축 버튼
- 육성 입력 시 자동 보유 처리
- 사용 횟수 기본값 1
- SQLite 로컬 영구 저장
- 메타 파티·피해 유형·버프 태그·육성도·돌파·전용 무기·최대 사용 횟수를 함께 반영한 복수 파티 전체 최적화
- 추천 구성 A/B/C 전환 UI
  - 같은 보유풀에서 서로 다른 고점 배분안을 비교
  - 예: 치사, 데니아, 모니에, 파수인처럼 여러 파티가 경쟁하는 핵심 파츠를 전체 점수 기준으로 배분
- 방랑자 속성별 폼은 같은 사용 슬롯을 공유
  - 기류 방랑자를 쓰면 회절/인멸/전도 방랑자는 같은 사용 가능 횟수 안에서 같이 소모됨
- 모바일 반응형 UI

## 파티 추천 방향

추천 엔진은 단순히 한 파티의 최고점만 고르지 않고, 보유풀 전체에서 가능한 고점 파티 수를 최대화합니다.

## 구조

- `server.py`: 정적 파일 서버, JSON API, SQLite 저장, 추천 엔진
- `data/characters.json`: UI와 추천 엔진이 공유하는 캐릭터 카탈로그
- `data/team_rules.json`: 검증된 메타 파티와 피해/버프 호환성 지식 베이스
- `static/`: 프레임워크 없는 웹 UI
- `scripts/update_nanoka_assets.py`: Nanoka 캐릭터 이미지/Live2D 경로 갱신 보조 스크립트
- `scripts/check_live2d_assets.py`: Live2D skel/atlas/texture 접근성 검사 스크립트
- `tests/`: 추천 배분, 카탈로그, 저장, UI 번들 회귀 테스트

## 데이터와 이미지 출처

캐릭터 이미지와 Live2D 경로는 Nanoka의 공개 정적 데이터를 기반으로 로컬에 저장해 사용합니다. 파티 룰은 인터넷 공개 가이드와 사용자가 검증한 조합 지식을 `data/team_rules.json`에 반영하는 방식입니다.
