# 모델 ZIP 놓는 곳

Google Drive에서 받은 `resonance-qwen3-4b-runtime.zip`을 압축 해제하지 말고 이 폴더에 넣어 주세요.

프로젝트 루트에서 다음 명령만 실행하면 ZIP을 자동으로 찾아 설치해요.

```bash
python scripts/install_model_bundle.py
```

ZIP을 다른 폴더에 보관하고 싶다면 기존처럼 경로를 직접 지정할 수도 있어요.

```bash
python scripts/install_model_bundle.py "/원하는/경로/model.zip"
```
